Library Management System

A console-based Library Management System developed in C programming. The project is designed to manage books, issue and return records, users, due dates, and late-return fines.

Features

    Add Record
    Remove Record
    Search Record
    List Records
    Issue Records
    Save Records
    Return Records

How to Complie

    using GCC : gcc*.c -o output (or)
    using makefile : make

How to Run

    ./output
